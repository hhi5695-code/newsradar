# 상한가

코스피·코스닥 상한가를 거래일마다 모아, 뉴스에 나온 이유로 테마를 나누는 정적 웹사이트입니다. 화면 문구는 한국어입니다.

데이터는 네이버금융 공개 시세와 뉴스 검색만 사용합니다. 유료 API나 키는 쓰지 않습니다. KRX 사이트가 로그인 없이 빈 응답을 주기 때문에 pykrx는 쓰지 않습니다. 종목 일봉은 네이버 가격 API이고, 상한가 기준가는 그 응답의 전일 대비 등락을 뺀 값입니다. 거래일 달력만 코스피 `siseJson`을 씁니다. 종목, 가격, 이유 문장은 받아 온 값만 저장하고, 이유를 찾지 못하면 `이유 미확인`으로 둡니다.

시세·테마·요약·차트는 커밋 전에 AES-256-GCM으로 암호화됩니다. 키는 `SITE_PASSWORD`로 PBKDF2-HMAC-SHA256(210000회) 유도합니다. 브라우저는 scrypt를 만들 수 없어서 PBKDF2를 씁니다. 저장소에 남는 것은 암호문이 들어 있는 `site/data/enc/*.bin`과, 비밀번호가 아닌 솔트·반복 횟수만 있는 `site/data/crypto.json`입니다. 암호는 GitHub Actions 비밀로만 읽고 커밋하지 않습니다. 사이트는 먼저 암호 화면만 보여주고, 브라우저 Web Crypto로 푼 뒤에 화면을 엽니다. “이 기기에 암호 기억”을 켜면 그 브라우저의 localStorage에만 남고 서버로는 나가지 않습니다.

검색 수집을 줄이려고 `robots.txt`는 전체 경로를 막고, 페이지에는 `noindex,nofollow`를 넣었습니다. 화면 스크립트는 `site/js/src/app.js`를 난독화한 `site/js/app.js`입니다.

ETF, ETN, 스팩, 우선주는 뺍니다. 상한가는 기준가의 가격제한폭(30%, 호가단위 절사)과 당일 고가·종가가 정확히 같을 때로 잡습니다. 급등만 한 종목은 넣지 않습니다.

## 화면

- **오늘**: 최근 거래일의 상한가. 테마 번호와 대/중/소, 한 줄 이유.
- **테마달력**: 2026년 1월부터. 달의 테마(1-1, 1-2, … 11-1)와 종목. 날짜를 누르면 그날의 상한가.
- 종목을 누르면 일봉·주봉·월봉 차트. 주봉에는 240주선, 월봉에는 120개월선.

테마는 그 달 안에서만 번호가 이어집니다. 다음 달의 같은 테마는 새 번호입니다.

대/중/소 기준은 [`site/data/config.json`](site/data/config.json)에 있습니다.

- 대: 그 달 테마의 상한가 종목이 `largeMinCount`(3)개 이상이고, 하나 이상이 주봉 240선 위이거나 그 선을 돌파
- 중: 종목이 `mediumCount`(2)개, 또는 3개 이상이지만 주봉 240선 위/돌파가 없음
- 소: 종목 1개

종목 수는 같은 달·같은 테마의 서로 다른 종목 수입니다. 같은 종목이 여러 번 상한가를 가도 한 종목으로 셉니다. 주봉 240선은 그 상한가일의 주봉까지로 계산합니다. 240주가 안 되면 위/돌파로 치지 않습니다.

기준을 바꾼 뒤 숫자를 다시 매기려면 원본을 유지한 채 아래를 실행합니다.

```bash
python3 collector/collect.py --rebuild
```

## 암호

저장소는 공개로 두고 GitHub Pages 무료 호스팅을 씁니다. 시세를 읽으려면 저장소 비밀이 필요합니다.

1. 저장소 **Settings → Secrets and variables → Actions**
2. **New repository secret**
3. Name에 `SITE_PASSWORD`, Secret에 사이트 암호를 넣고 **Add secret**

비밀이 없으면 `상한가 수집` 워크플로는 바로 실패하고, 평문 시세는 만들지 않습니다. 비밀을 저장한 뒤 **Actions → 상한가 수집 → Run workflow**로 첫 수집을 실행합니다. 암호화된 수집 이력이 없으면 2026-01-02부터 오늘까지 거래일을 채웁니다.

로컬에서 같은 암호로 수집하려면 `SITE_PASSWORD` 환경 변수만 넣고 `pip install -r collector/requirements.txt` 후 실행합니다. 화면 스크립트를 고친 뒤에는 `bash collector/build_js.sh`로 `site/js/app.js`를 다시 만듭니다.

## 자동 수집

GitHub Actions `상한가 수집`은 평일 16:30 KST(07:30 UTC)에 하루에 한 번만 돌아갑니다. 장중 재조회는 없습니다. 휴장일이면 건너뜁니다. 암호문만 `site/data`에 커밋하고 GitHub Pages로 배포합니다.

## 수동 실행

GitHub 저장소 → Actions → **상한가 수집** → Run workflow.

- 날짜를 비우면, 이미 수집 이력이 있을 때는 한국시간 오늘만 수집합니다.
- **backfill**을 켜면 2026-01-02부터 오늘까지 빠진 거래일을 채웁니다.

로컬:

```bash
pip install -r collector/requirements.txt
SITE_PASSWORD='암호' python3 collector/collect.py --backfill
SITE_PASSWORD='암호' python3 collector/collect.py --date 2026-11-23
python3 -m http.server -d site 8000
```

## 전수조사

`python3 collector/audit.py`는 2026-01-02부터 오늘까지 거래일마다 상한가를 두 소스로 대조합니다. 네이버 일별시세의 거래소 기준가·상한 표시와, FinanceDataReader 일봉(전일 종가 대비 약 29.5% 이상이고 종가가 그 가격의 상한가)입니다. 2026-03-08부터는 KRX 일별 스냅샷도 봅니다. 상장 첫날은 공모가의 400%, 거래량 0은 거래정지로 제외하고, 코넥스·우선주·스팩·ETF·ETN은 뺍니다. 이유는 그날 기사나 공시 문장만 쓰고, 없으면 `이유 미확인`으로 두며 서로 합치지 않습니다. 종목이 적힌 보고서는 `SITE_PASSWORD`가 있을 때만 `audit/report.bin`으로 암호화해 저장합니다.

## 한계

- 수집 시점에 네이버 종목 목록에 있는 종목만 포함합니다. 그 전에 상장폐지된 종목은 빠집니다.
- 기준가는 네이버가 주는 전일 대비 등락으로 계산합니다. 등락이 없으면 그날은 건너뜁니다.
- 뉴스에서 이유 문장을 못 찾으면 테마를 합치지 않고 `이유 미확인`으로 따로 둡니다.
- 공개 저장소의 암호는 데이터를 숨기는 자물쇠입니다. 암호를 아는 사람은 사이트에서 시세를 볼 수 있습니다.
